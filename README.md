# Pluviam Discovery — web estática

Sitio de demostración de Pluviam para Cloudflare Pages.

## Incluye

- Página premium adaptable a móvil y escritorio.
- Cinco perspectivas para explorar el valor de la captación de lluvia.
- Tres recorridos: vivienda, empresa y profesionales.
- Evaluación orientativa de cinco preguntas: cálculo local de potencial teórico anual.
- Contacto opcional mediante borrador de correo; no hay envíos automáticos.

## Uso

La web no necesita dependencias, compilación ni cuentas. Abre `index.html` para una vista previa o publica el directorio raíz en Cloudflare Pages. Si conectas GitHub, deja vacío el comando de compilación y usa `.` como carpeta de salida.

**Esta versión es una demostración visual independiente.** No incluye formularios de registro, pagos, portal de clientes, backend ni estudio técnico vinculante. La cifra de litros es una estimación matemática basada en valores editables; no es ahorro, potabilidad, autonomía ni producción garantizada.

## Archivos

- `index.html`: HTML + CSS + JavaScript de toda la página.
- `favicon.svg`: icono.
- `_headers`: cabeceras HTTP para archivos estáticos, incluyendo una política de noindex de la versión de demostración.
- `robots.txt`: evita el rastreo mientras está en revisión.

Antes de publicación comercial, adapta las configuraciones de robots, el aviso integral y los servicios de atención pertinentes.
